Computer Science Principles AP

You will not be able to take this exam this year as I am not teaching this class

The AP Computer Science Principles Exam assesses student understanding of the computational thinking practices and learning objectives outlined in the course framework. The exam consists of the Create performance task and an end-of-course AP Exam. The Create performance task requires at least 9 hours of dedicated class time for students to complete. The end-ofcourse exam is 3 hours long and includes 70 multiple-choice questions and 2 written response questions related to their Create performance task. The two questions include four distinct prompts: Written Response 1, Written Response 2(a), Written Response 2(b), and Written Response 2(c). Students will be given their student-authored Personalized Project Reference to use when answering these written response prompts. The multiple-choice section will include three different types of questions (in the following order on the exam): single-select questions, single-selectvquestions with a reading passage about a computing innovation, and multi-select questions. As part of the exam, students will be given the Exam Reference Sheet, which contains both block-based and text-based programming constructs and establishes a common way to communicate programming concepts for the purpose of the exam. The details of the exam, including weighting and timing, can be found below:

  • multiple choice (70 questions, 70% of score, 120 minutes)
  • create performance task (5 questions, 30% of score, 60 minutes)

The AP Computer Science A Exam assesses student understanding of the computational thinking practices and learning objectives outlined in the course framework. The exam is 3 hours long and includes 42 multiple-choice questions and 4 free-response questions. As part of the exam, students will be given the Java Quick Reference, which lists accessible methods from the Java library that may be included on the exam. The details of the exam, including exam weighting and timing, can be found below:

  • multiple choice (42 questions, 55% of score, 90 minutes)
  • free-response (4 questions, 45% of score, 90 minutes)
